# 修仙者 · 캐릭터 카드

## 창생 결과

| 항목 | 내용 |
|---|---|
| **이름** | 무명(無名). 마을에서는 '온가네 아이', '유배 나리 댁 아이'라고 부른다 |
| **성씨** | 온(溫). 족보에서 제적됨 |
| **종족** | 인족(人族) |
| **성별·나이** | 남 · 14세 (경화 3년 봄생) |
| **외형** | 키 크고 호리호리함 · 수려한 용모 · 햇볕에 그을린 피부와 손바닥의 굳은살 |
| **출신** | 유배 관리의 자식. 아버지 온수경(溫守經)은 직간(直諫)으로 쫓겨난 간관. 태어나기 전에 유배됨. 부모 모두 생존 |
| **시작 계·지역** | 하계(下界) · 만요령 접경 · 대옹 서변 사가둔(謝家屯) |
| **영근** | 수목(水木) 쌍령근 · 상생 · 중품 6할 · 균형 5:5 *(본인은 아직 모름)* |
| **체질** | 다맥(多脈): 흡수 +3할, 운기 불안정·주화입마 위험 |
| **재능** | 견인(堅忍): 고통과 지루함을 견딤. 한계를 넘겨도 멈추지 않음 |
| **시작 경지** | 미입도 · 자연 유입 |
| **성격** | 신중 · 집요 · 다정 · 실리 |
| **지금의 바람** | 살아남는다 · 사가를 이용한다 |
| **평생의 도** | 장생불사 · 의선(醫仙) · 평범하고 풍족한 삶 |
| **수련 속도** | 수목 쌍수 공법 1.95 / 목 단일 범급 하품 공법 약 1.33 |

## 현재 상태 (第七章 종료 · 경화 17년 8월 13일 밤, 사가둔 온가)

- **영근(확인)**: 수목 쌍령근 · 중품 6할 · 균형 (사가 측령석 사측. 본인도 앎)
- **경지**: 미입도 → 운기 입문. 기해에 이슬 한 방울만 한 영기가 고이기 시작(흩어지지 않음). 기종 형성 예상 8월 20일 무렵
- **주목**: 승선사 주사 염적이 직접 보고 "범인이 아니구나"라고 함. 공식 점고 기록은 "이상 없음"
- **증상**: 운기를 시작하며 경련이 멎음. 큰 울림이 오면 흘려보내기로 버팀
- **시한**: 매일 운기를 유지하면 진행 정지(약 97일에서 멈춤). 기종이 맺히면 해결
- **공법**: 『운택양목결』 상권(연기 1~3층) · 2층 구결까지 암송 · 범급 상품 · 수목 쌍수 (책은 장원 밖 반출 금지)
- **기록**: 증상·단서 책자에 측천규 관련 고자 12자(10자 해독: 大衍測天 / 四九爲用 一遁, 2자 판독 불가), 바닥 규표의 묘사, '측천규'라는 이름
- **요령**: 흘려보내기 — 남는 맥을 배수로로 써서 운행을 안정시킴. 큰 울림에도 흐름을 지킴
- **신분**: 사가 가신 (경화 17년 8월 10일 ~ 27년 8월 10일) · 녹단목 가신패 · 문약에 영인
- **월례**: 매달 초하루 청로환 1알 + 은 5냥 (첫 지급 9월 1일)
- **기예**: 경서와 글(능숙) · 필사(능숙) · 맥진(입문) · 약초(기초) · 고자(古字) 약간
- **재물**: 은 3냥 9전 80문. 가계 저축 은 2냥(어머니가 관리), 가계 연 수입 약 은 12냥
- **비밀**: '대연측천(大衍測天)'의 해독. 아버지의 사본 「연천각 영재수납록」(『춘추좌전』 표지 안). 가족만 앎
- **물품**: 『춘추좌전(春秋左傳)』 주해본 · 『백초소기(百草小記)』 · 자호필(紫毫筆) · 증상·단서 기록 책자 · 삼베 밧줄 10장 · 등잔 · 산초·쑥 주머니
- **신분**: 유배 죄인의 자식. 연좌로 유배지 이탈 금지. 사가 보증 아래 사가둔에 안치
