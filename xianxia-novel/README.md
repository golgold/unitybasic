# 천연계(天衍界) — 인터랙티브 선협 장편

인터랙티브 수선 소설의 설정과 기록을 보관하는 폴더입니다. Unity 프로젝트와는 관계가 없으며, `Assets/` 밖에 있으므로 Unity는 이 폴더를 무시합니다.

| 파일 | 내용 |
|---|---|
| `character.md` | 주인공 캐릭터 카드 (창생 결과 + 현재 상태) |
| `world.md` | 세계 설정집 공개본 (주인공과 독자가 알 수 있는 범위) |
| `log.md` | 장별 수행록(修行錄) |
| `resume.md` | 연재 이어가기용 요약본 (새 대화에 붙여 넣는 용도) |
| `chapters/` | 본문 |
| `author_notes_SPOILER.md` | ⚠ **작가 전용 비밀 설정. 스포일러입니다.** 새 대화에서 이어갈 때 읽지 말고 붙여 넣기만 하세요. |

## 새 대화에서 이어가는 법

1. 처음에 쓰셨던 마스터 프롬프트를 붙여 넣습니다.
2. `resume.md` 전체를 붙여 넣습니다.
3. `author_notes_SPOILER.md`를 붙여 넣습니다. 작가가 설정을 일관되게 지키는 데 필요합니다.
4. "마지막 장의 선택지부터 이어서"라고 요청합니다.
