# 캐릭터 카드 — 고진(顧辰)

| 항목 | 내용 |
|---|---|
| 종족 | 인족(人族) |
| 성별·나이 | 남, 경안 8년 4월 16일생. 시작 시 만 9세(세는나이 10) |
| 외형 | 눈길을 끄는 수려한 얼굴 |
| 시작 지역 | 하계 범진, 운몽산 아래 마을 |
| 출신 | 운몽종 전공장로 고씨 가문 방계. 아버지 고평(범인, 본가 영전 관리), 어머니 윤하, 여동생 연아(6) |
| 영근 | 수·목 쌍령근 상품, 고르게 섞임(상생). 일곱 살 측령으로 본인·가문이 앎 |
| 체질 | 현수체(玄水體) — 영력 그릇이 깊다. 경지 안 수련이 조금 느린 대신 영력이 두텁다 |
| 혈맥 | 어머니 쪽에 흐르는 특별한 뱀 요족의 피 (고진은 모름) |
| 재능 | 끈기 |
| 시작 경지 | 미입도(기감만) |
| 첫 장면 | 운몽종 입문 시험 당일 |
| 성격 | 신중함, 과묵함, 다정함, 눈치 빠름 |
| 목표 | 지금의 바람: 입문 시험 합격 / 평생의 도: 장생 |
| 난이도 | 시한·거래·부상·죽음 어려움 / 자원·경쟁·가족 보통 |
| 강조 | 수련 서사(가장 강조), 고대 문명·유적, 세력 간 대립 / 연정: 중심 서사 |
| 진행 방식 | 행동 선택지는 클릭형 카드, 태도·조합·직접 제안은 글 / 기록은 공유 폴더 + 저장소(작가 노트 포함) |

## 현재 상태 (第二十一章 끝)
- 경안 18년 11월 3일 자시, 조사당 뒤 바위틈(진주가 사당 뒤 영주와 같은 박자로 뜀, 환영을 봄). 약원 기명(종주 직속 증인), 종주·방목과 한편. 연기 2층 대원만, 응로술, 인근술, 행공, 수·목 상생, 『청목양근』. 엽전 25문, 영석 27, 취기단 6, 소청의 부싯돌.
