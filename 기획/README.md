## 기획 배경
- **사회**: 2025년 무력 분쟁 65개로 1946년 집계 이래 최다 (PRIO, 2026). 종군기자 영화 〈시빌 워: 분열의 시대〉 1억 달러 흥행.
- **시장**: 기존 잠입액션(메탈기어 솔리드 V, 스플린터 셀)은 발각 = 전투 개시라 긴장이 쉽게 풀린다. 발각 = 생존 위기인 약자의 생존 게임(Outlast 1편 640만 장, This War of Mine 900만 장+, 둘 다 무료 배포 포함)도 크게 팔렸다. 본작은 잠입액션의 조작에 **약자로 버티는 긴장**을 더한다.

## 기획 의도
1. **싸우지 않는 잠입**: 돌 던지기 등으로 시선 돌리기, 죽일 수 없고 밀치고 도망칠 뿐, 붙잡히면 체포 · 필름 압수 · 처형
2. **자유로운 전장**: 지역을 골라 들어가는 구조, 지역 안은 오픈월드처럼 자유
3. **사진이 바꾸는 결말**: 한정된 필름 → 무엇을 찍을지 선택, 공개한 사진 → 여론 · 전황 변화, 생사 × 여론 → 다양한 결말

## 핵심 게임플레이
- **코어 루프**: 취재지 선택(지역 · 장비 · 필름) → 잠입 · 탐색(순찰 · 검문 회피) → 촬영(증거 · 결정적 순간) → 보존 · 반출(필름 은닉) → 송고 · 공개(공개할 사진 선택) → 전황 · 다음 취재지 변화 → 다시 취재
- **잠입**: 경계 4단계 평상 → 의심 → 경계 → 발각. 돌 던지기 등으로 시선을 돌릴 수 있고, 발각되면 밀치기 · 도주는 가능하지만 죽일 수는 없음. 붙잡히면 구금 · 필름 압수
- **촬영**: 셔터음 · 플래시가 경계를 올림. 필름 컷수 제한(기계식 필름 카메라 2대, 12롤 × 36컷)이라 찍을 장면을 골라야 함
- **송고**: 공개한 사진에 따라 여론 · 전황, 검문소 · 거리 · 인물 반응이 바뀜

## 세계관
- **시간**: 2003년 7월 10일부터 약 3주
- **공간**: 가상 내륙국 카르티아(인구 400만), 포위된 수도 베르산. 미라강이 도시를 남북으로 가름 (북쪽 언덕 = 반란군 포대, 남쪽 = 정부)
- **두 진영**: 공화국 정부(공보국이 기자증으로 보도 통제 · 감시) vs 2003년 3월 쿠데타로 생긴 반란군 '국민군'
- **주요 무대**: 중앙시장과 구시가지 / 호텔 아마네라(프레스센터) / 구 의회 건물(정부 본부) / 북쪽 언덕의 옛 수도원(반란군 전선 사령부) / 미라강과 어부의 길 / 구호단체 사무소와 남부 호수(위성 송신기, 국경으로 가는 길)

## 전개
| 챕터 | 제목 | 내용 |
| --- | --- | --- |
| PROLOGUE | 휘말림 | 시장 폭격 · 첫 사진 (튜토리얼) |
| CH.1 | 세계의 시선 | 프레스센터 잠입, 몰래 송고 · 세계의 주목 |
| CH.2 | 취재 | 붉은 신호탄 발견 · 마르타의 죽음, 마르타가 숨긴 필름 |
| CH.3 | 잠입 | 두 본부 중 **한 곳만** 잠입 — A 정부 본부(민병대 처형 명단 · 정부 묵인 문서) / B 반란군 전선 사령부(시장 포격 명령서 · 작전 지도) |
| CH.4 | 추적 | 두 진영의 추격 · 다닐의 무전 기록 |
| CH.5 | 반출 | 구호단체 송신소 잠입 · 국경 탈출, 무엇을 공개할지 선택 |

**핵심 진실**: 시장을 쏜 건 반란군, 알고도 막지 않은 건 정부. 전체 진실 = 반란군의 포격 명령(명령서 또는 다닐의 기록) + 정부의 묵인(묵인 문서 또는 마르타의 필름)

**대표 엔딩 (생사 × 공개 내용 — 이 밖에도 상황에 따라 다양한 엔딩)**
- A. 국경 너머의 증언 — 생존 · 두 진영의 책임 공개
- B. 이름 옆의 ‘故’ — 사망 · 두 진영의 책임 공개
- C. 한쪽의 전쟁 — 한 진영의 죄만 공개
- D. 잊힌 전쟁 — 참혹한 사진만 공개
